## Рабочие папки

| Путь | Назначение |
|---|---|
| `build/dayplanner-android/` | Актуальные исходники Android, локальный ключ подписи и Android-проект |
| `build/dayplanner-pc/` | Актуальные исходники Windows и сервер рейтинга `server/` |
| `build/env.ps1` | Локальное окружение сборки Windows: JDK, SDK/NDK, Rust GNU, MinGW |
| `dist/` | Готовые сборки текущей версии |
| `tools/` | Сборка Windows и безопасный локальный просмотр интерфейса |
| `tests/navigation.html` | Проверки адаптивной панели навигации |

Старые `dayplanner/`, `dayplanner-github/`, упаковочные копии и входные архивы удалены
по решению владельца. Единственные рабочие версии теперь находятся в `build/`.
Каталоги не перемещены: это сохраняет работоспособность сгенерированного Android-проекта.

## Архитектура

Rust + SQLite (`core/`) → единый API `api(cmd, args, now)` → Tauri 2 → HTML/CSS/JS (`app/ui/`).
Android-интеграция написана на Kotlin в `plugins/planner-native/android/`.
Windows-интеграция: трей, автозапуск и окна напоминаний в `app/src-tauri/src/desktop.rs`.
Общее ядро, UI-скрипты и стили в двух версиях совпадают; изменения переносите в обе копии.

Синхронизация: ntfy, локальная сеть (TCP/UDP), экспорт/импорт файла;
данные группы шифруются ChaCha20-Poly1305. Сервер рейтинга — отдельный, на axum.
Dropbox — дополнительный транспорт с тем же слиянием; токены импортируются на каждом
устройстве локально, в APK/EXE их нет. Пароль интерфейса не является полным шифрованием SQLite.

## Сборка в этом окружении

Из `E:\RustDnevnik`:

```powershell
# Android: подписанный APK, arm64 + armv7
.\build\dayplanner-android\build-apk.ps1

# Windows: EXE и установщики
.\tools\build-pc.ps1

# Только EXE
.\tools\build-pc.ps1 -NoBundle

# Тесты общего ядра
. .\build\env.ps1
cargo test -p planner-core --locked --offline --manifest-path build\dayplanner-pc\Cargo.toml
```

Используется GNU-тулчейн Rust с MinGW, Visual Studio для этой локальной сборки не нужна.
Подробности подписи: `build/dayplanner-android/BUILD_ANDROID.md`.
Ключ в `build/dayplanner-android/keys/`, пароли — только в локальном
`app/src-tauri/gen/android/keystore.properties`. **Не публиковать эти файлы.**

## Просмотр и проверки интерфейса

```powershell
python tools\preview-ui.py
```

- ПК: http://127.0.0.1:8788/pc/
- Android: http://127.0.0.1:8788/android/
- Проверки: http://127.0.0.1:8788/tests/navigation.html → «Запустить проверки».

Сервер отдаёт только интерфейс и тестовую страницу, а не ключи и рабочие файлы.
Браузерный режим использует демонстрационные данные, не настоящую базу приложения.
ZIP-импорт, пароль и настоящий Dropbox доступны в установленном приложении;
демо не сохраняет облачные токены в браузере.

## Проверки 0.2.0

54 теста Rust (включая подменённый Dropbox и конфликт ревизий), 576 сочетаний вёрстки,
140 браузерных проверок новых функций и 3 проверки Android-отступов.
Настоящий Dropbox и физические Android-устройства при разработке не использовались.

## Предыдущие изменения 0.1.2

- Компактная боковая навигация на ПК вместо полосы на всю высоту.
- Единая геометрия кнопок, иконок и активного состояния во всех четырёх темах.
- Android: панель не растягивается, нижний системный отступ учитывается один раз,
  вырезы экрана и боковые отступы учитываются после поворота и изменения размеров.
- Android-мост измеряет только фактическое перекрытие WebView системными панелями:
  уже применённые системой отступы не добавляются повторно.

Проверено: 40 тестов ядра, 384 сочетания вёрстки, подмена Android-моста для проверки
масштабирования отступов, сборка Windows и подписанного Android APK.
Физические Android-устройства в этой проверке не использовались.
